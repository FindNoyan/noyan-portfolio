# Noyan — Portfolio Site

Personal portfolio site built with React, Vite, and Tailwind CSS. Includes a
typed-terminal hero, skills overview, selected work, and contact section.

## Tech stack

- React 19 + Vite
- Tailwind CSS

## Getting started

```bash
npm install
npm run dev
```

Open http://localhost:5173 to view it locally.

## Build

```bash
npm run build
```

Outputs a production build to `dist/`.

## Deploy

This project deploys cleanly to Vercel, Netlify, or GitHub Pages — connect
the repo and use `npm run build` with `dist` as the output directory.
